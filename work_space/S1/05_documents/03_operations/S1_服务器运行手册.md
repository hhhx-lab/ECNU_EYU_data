## 1. 这是什么 / 不是什么

### 1.1 S1 做什么

S1 是 MONAI 3D UNet 多任务模型：

| 输出头 | 类别 | 含义 |
| --- | --- | --- |
| tumor | 0/1/2/3 | BG / NETC / SNFH / ET |
| RC | 0/1 | BG / recurrence component |

训练默认策略（`configs/multitask_v1_full.yaml`）：

- 每模态 **非零脑区 Z-score**（训练/验证/推理一致）
- **病灶均衡采样**：约 80% 连通病灶 crop，20% 随机脑区
- 轻量增强（翻转 / 小仿射 / gamma / 噪声 / bias field）
- **`batch_size=1` + `gradient_accumulation=2` + AMP（BF16 优先）**
- 验证：**完整体积 joint sliding-window**（不是中心 crop）
- **`best.pth` 按官方兼容 `checkpoint_score` 选择**（不是 val_loss）
- LR scheduler + early stopping；监控 RC uncertainty 权重

### 1.2 real-only 定义（必须遵守）

```text
G2 QC 通过的真实病例
+ 可用 corrected label（若有）
+ G2 固定 train/val/test split
+ 通道顺序 t1n, t1c, t2w, t2f
+ 不使用 G1 T2W completion 输出
+ 不使用 G1 diffusion synthetic 输出
+ internal locked test 只记清单，不进训练 view
```

### 1.3 不要做的事

1. 不要用 `scripts/10_create_full_split.py` 做正式 baseline（那是随机临时划分）。
2. 不要把 locked test 放进 `real_only_cases`。
3. 不要直接扫全库原始目录训练，绕过 G2 mapping/split。
4. 不要在 16/24GB 卡上硬跑默认 96³。
5. 不要跳过 audit；脚本已强制 audit PASS 才能训练。

## 5. GPU / 显存要求（OOM 相关）

### 5.1 硬性要求

| 项 | 要求 |
| --- | --- |
| GPU | 必须有 CUDA |
| 显存 | **默认 ≥ 40GB** |
| 推荐 | A100 40/80GB 或 H100 |
| 训练配置 | `batch_size=1`, `grad_accum=2`, AMP auto |

脚本在开训前读取 `torch.cuda.get_device_properties(0).total_memory`：  
若 `< S1_MIN_GPU_GB`（默认 40）且未设置 `S1_ALLOW_SMALL_GPU=1`，**直接退出**。

### 5.2 提交时如何要到大卡

**NYU 示例：**

```bash
cd "${PROJECT_ROOT}" && mkdir -p logs
sbatch --gres=gpu:a100:1 \
  --export=ALL,PROJ="${PROJECT_ROOT}" \
  work_space/S1/slurm/01_s1_realonly.slurm
```

**ECNU 示例：**

```bash
cd "${PROJECT_ROOT}" && mkdir -p logs
sbatch -p a100 --gres=gpu:NVIDIAA100-PCIE-40GB:1 \
  --export=ALL,PROJ="${PROJECT_ROOT}",CONDA_SH=/path/to/conda.sh,CONDA_ENV=brats2026_s1 \
  work_space/S1/slurm/01_s1_realonly.slurm
```

> 注意：脚本里默认写的是 `#SBATCH --gres=gpu:1`，**这只保证“有 GPU”**，不保证 40GB。  
> 请在 `sbatch` 命令行再加 gres/partition，命令行参数会覆盖/补充资源请求。

### 5.3 若仍然 OOM

按顺序，不要跳步：

1. 确认日志里是 `batch_size=1 grad_accum=2 amp=...`  
2. 确认 GPU ≥ 40GB  
3. 把配置改成 80³（同时改 train 与 validation）：

```yaml
# configs/multitask_v1_full.yaml
train:
  patch_size: [80, 80, 80]
validation:
  roi_size: [80, 80, 80]
```

4. 万不得已才缩小 `model.channels`  
5. 只有在你已改到 80³ 且清楚风险时，才允许：

```bash
sbatch --export=ALL,PROJ="${PROJECT_ROOT}",S1_ALLOW_SMALL_GPU=1,S1_MIN_GPU_GB=24 \
  work_space/S1/slurm/01_s1_realonly.slurm
```

## 7. 作业内部流程（脚本保证顺序）

`run_s1_realonly.sh` 固定 6 个阶段，任一步失败即 `exit 1`：

| 阶段 | 内容 | 失败时 |
| --- | --- | --- |
| 0 | 检查 PROJ / repo / raw / G2 脚本 / conda.sh | 直接退出，不开训 |
| 1 | 激活 conda；import 全套依赖；CUDA + 显存检查 | 缺包/无 GPU/显存不足则退出 |
| 2 | G2 real-only mapping + fixed split | intake 失败则退出 |
| 3 | 重建 S1 view（symlink）+ 写 train/val 列表 | 缺文件/泄漏/过小 split 则退出 |
| 3b/3c | 生成 tumor/RC 标签 + **严格 audit** | 任一例不完整则退出 |
| 4 | `trainer_v1_final.py --config multitask_v1_full.yaml` | 训练异常则作业失败 |
| 5 | 检查 `latest.pth` 是否写出 | 缺失则失败 |

额外安全项：

- 重建 view 时 **只删除** `work_space/S1/...` 下的 view，不会动 raw  
- train/val case id 若重叠会失败  
- audit 检查 4 模态、seg、tumor_label、rc_label，以及 split 列表是否都能在 view 中找到  
- 断链 symlink 会判失败

## 8. 常用覆盖变量

通过 `sbatch --export=ALL,VAR=value,...` 传入：

| 变量 | 默认 | 含义 |
| --- | --- | --- |
| `PROJ` | 从脚本路径推断 | 项目根 |
| `RAW_DATA_DIR` | `$PROJ/work_space/G1/data/raw/MICCAI-...-Training` | raw 根目录 |
| `CONDA_SH` | `/share/apps/anaconda3/2025.06/etc/profile.d/conda.sh` | conda 激活脚本 |
| `CONDA_ENV` | `brats2026_s1` | 环境名 |
| `G2_REFRESH_REALONLY` | `1` | 是否重跑 G2 intake |
| `S1_REBUILD_VIEW` | `1` | 是否重建 S1 view |
| `S1_MIN_GPU_GB` | `40` | 最低显存 |
| `S1_ALLOW_SMALL_GPU` | `0` | 是否允许低于阈值显存（危险） |
| `S1_CONFIG` | `configs/multitask_v1_full.yaml` | 训练配置 |
| `S1_RESUME` | 空 | 从 checkpoint 续训 |
| `S1_CHECKPOINT_DIR` | `.../S1/results/realonly/checkpoints` | 权重目录 |
| `S1_TENSORBOARD_DIR` | `.../S1/results/realonly/tensorboard` | TB 目录 |
| `S1_REALONLY_VIEW` | `.../S1/data/real_only_cases` | 训练 view |
| `BRATS_SPLIT_DIR` | `.../repository/data/splits` | split 文本目录 |

### 8.1 续训（resume）

```bash
CKPT="${PROJECT_ROOT}/work_space/S1/results/realonly/checkpoints/latest.pth"
sbatch --gres=gpu:a100:1 \
  --export=ALL,PROJ="${PROJECT_ROOT}",S1_RESUME="${CKPT}",S1_REBUILD_VIEW=0,G2_REFRESH_REALONLY=0 \
  work_space/S1/slurm/01_s1_realonly.slurm
```

说明：

- `S1_REBUILD_VIEW=0`：若已有 view 且 audit 通过则跳过重建（更快）  
- 若 audit 失败，脚本会自动回退为重建  
- `G2_REFRESH_REALONLY=0`：沿用已有 mapping/split（保证与上次一致）  

### 8.2 不刷新 G2、强制重建 view

```bash
sbatch --gres=gpu:a100:1 \
  --export=ALL,PROJ="${PROJECT_ROOT}",G2_REFRESH_REALONLY=0,S1_REBUILD_VIEW=1 \
  work_space/S1/slurm/01_s1_realonly.slurm
```

## 9. 训练超参与调参位置

主配置：

```text
work_space/S1/brats2026_multitask_S1_v2/repository/configs/multitask_v1_full.yaml
```

| 情况 | 改什么 |
| --- | --- |
| 显存不够 | 已是 `batch_size=1`；再改 `patch_size`/`roi_size` → 80³ |
| loss 震荡 | `train.lr`: `0.0003` → `0.0001` |
| 验证太慢 | `validation.every_n_epochs`: `1` → `2` 或 `5`（选 best 频率降低） |
| RC 权重被压太低 | 看 TB 的 `train/weight_rc`；收紧 `loss.max_log_sigma` 或 `use_uncertainty: false` |
| 续训 | 环境变量 `S1_RESUME` |

**不要**再把 `batch_size` 调回 2 除非你有 ≥80GB 且确认不 OOM。

## 11. 故障排查表

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `Missing S1 repository` / `PROJ does not exist` | `PROJ` 推错或未 export | `export PROJ=/真实项目根` 再提交 |
| `conda activation script missing` | `CONDA_SH` 不对 | 覆盖 `CONDA_SH` |
| `ModuleNotFoundError: monai` | 环境未激活或装错 env | `conda activate brats2026_s1` 并重装依赖 |
| `cuda available: False` | 分到 CPU 节点或 PyTorch CUDA 不匹配 | 检查 gres；重装匹配 CUDA 的 torch |
| `S1 requires >= 40GB` | 分到小显存卡 | `--gres=gpu:a100:1` 或改 80³ + 慎用 `S1_ALLOW_SMALL_GPU` |
| `raw data directory missing` | raw 未放到默认路径 | 设 `RAW_DATA_DIR` |
| `missing mapping ids` | split 与 mapping 不一致 | `G2_REFRESH_REALONLY=1` 重跑 intake |
| `audit ... incomplete cases` | view 缺模态/标签/断链 | 看报错 case；`S1_REBUILD_VIEW=1` 重建 |
| `failed to build labels` | seg 缺失或损坏 | 检查 G2 mapping 的 `seg_source_path` |
| `CUDA out of memory` | 仍超显存 | 确认 batch=1；改 80³；换 80GB 卡 |
| 日志找不到 | 没在项目根 `mkdir -p logs` 就 sbatch | 始终 `cd $PROJECT_ROOT && mkdir -p logs` |
| train/val 指标离谱 | 用了随机 split 或中心 crop 旧代码 | 确认跑的是新 trainer + G2 fixed split |

## 15. 一页纸命令汇总

```bash
export PROJECT_ROOT=/scratch/bf2260/ECNU_EYU_data
cd "${PROJECT_ROOT}"
mkdir -p logs

# 环境（一次）
# conda activate brats2026_s1 && python -c "import torch,monai; print(torch.cuda.is_available())"

# 正式训练
sbatch --gres=gpu:a100:1 \
  --export=ALL,PROJ="${PROJECT_ROOT}" \
  work_space/S1/slurm/01_s1_realonly.slurm

# 续训
sbatch --gres=gpu:a100:1 \
  --export=ALL,PROJ="${PROJECT_ROOT}",\
S1_RESUME="${PROJECT_ROOT}/work_space/S1/results/realonly/checkpoints/latest.pth",\
S1_REBUILD_VIEW=0,G2_REFRESH_REALONLY=0 \
  work_space/S1/slurm/01_s1_realonly.slurm

# 日志
tail -f logs/s1_realonly_<jobid>.out
```

按本文执行时，只要 **数据在、环境在、GPU≥40GB、在项目根提交**，脚本会在数据/环境错误时提前失败并给出明确原因，而不会静默开训。
