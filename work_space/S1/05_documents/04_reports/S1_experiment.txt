S1 experiment environment
=========================

文件用途
--------
这份文件只说明 S1 real-only baseline 的服务器环境怎么创建、怎么自检、Slurm 默认会用哪个环境。

S1 当前推荐入口：

  work_space/S1/slurm/01_s1_realonly.slurm

兼容旧入口（内部转调同一 runner）：

  work_space/G1/code/brats2025-latent-ensemble-synthesis-main/slurm/05_s1_realonly_nyu.slurm

完整运行手册：

  work_space/S1/docs/S1_服务器运行手册.md
  work_space/S1/brats2026_multitask_S1_v2/repository/docs/S1_服务器运行手册.md

默认 conda 环境名
----------------
brats2026_s1

Slurm 默认读取：

CONDA_SH=/share/apps/anaconda3/2025.06/etc/profile.d/conda.sh
CONDA_ENV=brats2026_s1

如果服务器 conda 路径不同，提交时覆盖：

sbatch --gres=gpu:a100:1 \
  --export=ALL,PROJ=/真实项目根目录,CONDA_SH=/path/to/conda.sh,CONDA_ENV=brats2026_s1 \
  work_space/S1/slurm/01_s1_realonly.slurm

推荐 Python / CUDA / PyTorch
----------------------------
1. Python: 3.10
2. PyTorch: 2.1.x 或更新的 2.x 稳定版
3. CUDA wheel: 优先 cu118；如果集群统一是 CUDA 12 且已验证 PyTorch CUDA 可用，可以改用 cu121。
4. 不要使用系统 Python、Homebrew Python 或 sudo pip。

创建环境
--------
建议在 login node 或 interactive session 创建环境，不要在正式 batch job 里临时安装依赖。

conda create -n brats2026_s1 python=3.10 -y
conda activate brats2026_s1

pip install torch torchvision --index-url https://download.pytorch.org/whl/cu118
pip install "monai>=1.3" numpy nibabel pyyaml tensorboard tqdm scikit-image scipy

如果服务器只能使用 CUDA 12.1 wheel，把第一条 pip 改成：

pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121

预期结果
--------
1. import 不报错。
2. GPU 节点上 cuda available 应该是 True。
3. 正式训练需要 gpu_memory_gb >= 40（默认 96^3 配置）。
4. 如果在 login node 无 GPU，cuda available 可能是 False；这种情况需要在 interactive GPU 节点再确认一次。

和 S1 代码的对应关系
--------------------
1. trainer_v1_final.py 需要 torch、tensorboard、pyyaml、numpy、monai。
2. datasets/brats_multitask_dataset.py 需要 monai、nibabel、numpy、torch、scipy。
3. models/multitask_unet.py 需要 monai.networks.nets.UNet。
4. metrics/brats_validation_metrics.py 需要 numpy、scipy。
5. G2 raw intake 脚本会检查 segmentation label 值，需要 nibabel。

正式运行前检查
--------------
1. 确认 raw data 已放在：
   work_space/G1/data/raw/MICCAI-LH-BraTS2025-MET-Challenge-Training/
2. 确认该目录里完整病例包含 t1n/t1c/t2w/t2f/seg。
3. 确认从项目根目录提交：
   cd $PROJECT_ROOT && mkdir -p logs && sbatch ... work_space/S1/slurm/01_s1_realonly.slurm
4. 确认 S1 Slurm 日志出现 dependency preflight: PASS 与 audit finished: PASS。

常见问题
--------
1. ModuleNotFoundError: monai
   说明没有激活 brats2026_s1，或 monai 装到了别的 Python 里。先 which python，再重新激活 conda。

2. cuda available: False
   先确认是不是在 GPU 节点；如果在 GPU 节点仍为 False，检查 PyTorch wheel 和驱动/CUDA 兼容性。

3. S1 requires >= 40GB
   默认 96^3 多任务训练需要大显存。请申请 A100/H100；或改 config 为 80^3 后谨慎使用 S1_ALLOW_SMALL_GPU=1。

4. 显存不足 (CUDA OOM)
   配置已是 batch_size=1 + grad_accum=2 + AMP。下一步把 patch_size 和 validation.roi_size 改为 [80,80,80]。

5. YAML 读取报错
   确认 pyyaml 已安装，并且从项目根目录通过官方 Slurm 入口运行。
