S3 experiment environment
=========================

文件用途
--------
这份文件只说明 S3 Swin UNETR real-only baseline 的服务器环境怎么创建、怎么自检、Slurm 默认会用哪个环境。
S3 当前入口是：

work_space/S3/slurm/01_s3_swin_unetr_realonly.slurm

默认 conda 环境名
----------------
brats2026_s3

Slurm 默认读取：

CONDA_SH=/share/apps/anaconda3/2025.06/etc/profile.d/conda.sh
CONDA_ENV=brats2026_s3

如果服务器 conda 路径不同，提交时覆盖：

sbatch --export=ALL,PROJ=/真实项目根目录,CONDA_SH=/path/to/conda.sh,CONDA_ENV=brats2026_s3 slurm/01_s3_swin_unetr_realonly.slurm

推荐 Python / CUDA / PyTorch
----------------------------
S3 原 README 使用的是比较稳定的一套 Swin UNETR 组合：

1. Python: 3.9
2. PyTorch: 2.0.1
3. torchvision: 0.15.2
4. MONAI: 1.3.0
5. CUDA wheel: cu118

S3 建议优先保持这套组合，不要和 S1/S2/S4 强行共用环境。

创建环境
--------
建议在 login node 或 interactive session 创建环境，不要在正式 batch job 里临时安装依赖。

conda create -n brats2026_s3 python=3.9 -y
conda activate brats2026_s3

pip install torch==2.0.1 torchvision==0.15.2 --index-url https://download.pytorch.org/whl/cu118
pip install "monai[all]==1.3.0" nibabel einops timm tensorboardX ml-collections scipy tqdm

依赖来源
--------
S3 code/Readme.md 原始环境为：

conda create -n brats_swin python=3.9 -y
pip install torch==2.0.1 torchvision==0.15.2 --index-url https://download.pytorch.org/whl/cu118
pip install monai[all]==1.3.0 nibabel einops timm tensorboardX ml-collections scipy tqdm

本项目只把环境名统一改成 brats2026_s3，依赖组合不变。

运行前自检
----------
激活环境后执行：

python - <<'PY'
import torch
import monai
import nibabel
import einops
import timm

print("torch:", torch.__version__)

print("cuda available:", torch.cuda.is_available())
print("gpu:", torch.cuda.get_device_name(0) if torch.cuda.is_available() else "CPU")

PY

预期结果
--------
1. import 不报错。
2. 能从 monai.networks.nets import SwinUNETR。
3. GPU 节点上 cuda available 应该是 True。
4. 如果在 login node 无 GPU，cuda available 可能是 False；这种情况需要在 interactive GPU 节点再确认一次。

和 S3 代码的对应关系
--------------------
1. main.py 使用 torch、MONAI SwinUNETR。
2. trainer.py 使用 scipy.ndimage、MONAI DiceMetric、tensorboardX。
3. utils/data_utils.py 使用 nibabel、MONAI transforms、MONAI Dataset/DataLoader。
4. make_split.py 会读取 G2 fixed split，不再使用旧随机 split 作为正式 baseline。

正式运行前检查
--------------
1. 确认 raw data 已放在：
   work_space/G1/data/raw/MICCAI-LH-BraTS2025-MET-Challenge-Training/
2. 确认完整病例包含 t1n/t1c/t2w/t2f/seg。
3. 确认缺 t2w、缺任一必要文件或仍含非法 label 值的病例会被 G2 raw intake 自动跳过；有 clean corrected label 的病例会自动使用 corrected label。
4. 确认 S3 Slurm 日志开头能打印 torch 版本和 cuda available。

常见问题
--------
1. cannot import name SwinUNETR
   说明 MONAI 版本不匹配。S3 优先使用 monai[all]==1.3.0。

2. tensorboardX not found
   在 brats2026_s3 里重新 pip install tensorboardX。

3. CUDA 可用但 OOM
   先保持 batch_size=1 和 use_checkpoint=true，再按 S3_服务器运行手册降低 ROI。

4. S3 跑出来的 split 数量和 S1/S2 不一致
   先检查 Slurm 是否真的运行了 G2 raw intake，并确认 make_split.py 使用的是 G2 fixed split JSON。
