# S3 服务器运行手册

## 1. 当前定位

S3 是 Swin UNETR 分割线。当前第一阶段只跑 real-only baseline，用来和 S2/S1 对比。S3 不依赖预先存在的 G2 结果文件；Slurm 会先从 raw data 刷新 G2 real-only mapping/split，优先使用 corrected labels，并自动跳过缺 `t2w`、缺任一必要文件或仍含非法 label 值的病例。

```text
t1n, t1c, t2w, t2f, seg
```

并且 split 优先使用 G2 固定 split，不再使用旧的硬编码服务器路径。

## 2. 环境配置

先按同目录下的环境文件创建并自检 conda 环境：

```text
work_space/S3/docs/S3_experiment.txt
```

S3 Slurm 默认使用：

```text
CONDA_SH=/share/apps/anaconda3/2025.06/etc/profile.d/conda.sh
CONDA_ENV=brats2026_s3
```

如果服务器 conda 激活脚本或环境名不同，提交时通过 `--export=ALL,CONDA_SH=...,CONDA_ENV=...` 覆盖。S3 建议按原 README 使用 Python 3.9 + PyTorch 2.0.1 + MONAI 1.3.0 的组合，不要和 S1/S2/S4 强行共用环境。

## 3. 输入数据

S3 Slurm 默认读取 raw data：

```text
work_space/G1/data/raw/MICCAI-LH-BraTS2025-MET-Challenge-Training/
```

然后运行：

```text
work_space/G2/code/g2_build_realonly_from_raw.py
```

生成：

```text
work_space/G2/results/manifests/nnunet_case_mapping_realonly.csv
work_space/G2/results/splits/splits_final_train_val_test.json
```

每个病例目录必须包含：

```text
<case_id>-t1n.nii.gz
<case_id>-t1c.nii.gz
<case_id>-t2w.nii.gz
<case_id>-t2f.nii.gz
<case_id>-seg.nii.gz
```

## 5. Slurm 会做什么

脚本位置：

```text
work_space/S3/slurm/01_s3_swin_unetr_realonly.slurm
```

执行步骤：

1. 自动推导或读取 `PROJ`。
2. 检查 S3 code、raw data、G2 raw intake 脚本、conda 激活脚本。
3. 激活 `brats2026_s3` 环境。
4. 从 raw data 刷新 G2 real-only mapping 和 split。
5. 缺 `t2w`、缺任一必要文件或仍含非法 label 值的病例只记录到 skipped CSV，不进入训练；有 clean corrected label 的病例会自动改用 corrected label。
6. 用 `make_split.py` 从 G2 fixed split 生成 S3 JSON。
7. 运行 `main.py` 训练 Swin UNETR。
8. 把训练日志同步写入 S3 results。

## 6. 输出位置

S3 split：

```text
work_space/S3/data/splits/s3_g2_fixed_split.json
```

S3 训练输出：

```text
work_space/S3/results/realonly/swin_unetr/
```

关键文件：

```text
work_space/S3/results/realonly/swin_unetr/train-<jobid>.log
work_space/S3/results/realonly/swin_unetr/best_model_dice.pth
```

Slurm 标准日志：

```text
work_space/S3/logs/s3_swin_realonly_<jobid>.out
work_space/S3/logs/s3_swin_realonly_<jobid>.err
```

## 7. 运行后检查

```bash
squeue -u $USER
tail -f ${PROJECT_ROOT}/work_space/S3/logs/s3_swin_realonly_<jobid>.out
tail -f ${PROJECT_ROOT}/work_space/S3/results/realonly/swin_unetr/train-<jobid>.log
```

日志里应该看到：

```text
valid_cases=...
skipped_cases=...
mode: g2_fixed_split
train: ...
val: ...
internal locked test: ...
Training Finished
```

如果当前 raw data 中有效病例数仍为 1295，默认结果应是 train 829、val 207、internal locked test 259。若缺文件或非法 label 病例被跳过，数量会自动按有效病例数重算。

## 8. 手工等价命令

```bash
PROJECT_ROOT=/scratch/bf2260/ECNU_EYU_data
cd ${PROJECT_ROOT}/work_space/S3/code

python ${PROJECT_ROOT}/work_space/G2/code/g2_build_realonly_from_raw.py \
  --project-root ${PROJECT_ROOT} \
  --data-root ${PROJECT_ROOT}/work_space/G1/data/raw/MICCAI-LH-BraTS2025-MET-Challenge-Training \
  --results-root ${PROJECT_ROOT}/work_space/G2/results \
  --fail-if-no-valid-cases

python make_split.py \
  --data-dir ${PROJECT_ROOT}/work_space/G1/data/raw/MICCAI-LH-BraTS2025-MET-Challenge-Training \
  --g2-split-json ${PROJECT_ROOT}/work_space/G2/results/splits/splits_final_train_val_test.json \
  --g2-mapping-csv ${PROJECT_ROOT}/work_space/G2/results/manifests/nnunet_case_mapping_realonly.csv \
  --project-root ${PROJECT_ROOT} \
  --output ${PROJECT_ROOT}/work_space/S3/data/splits/s3_g2_fixed_split.json

python main.py \
  --data_dir ${PROJECT_ROOT}/work_space/G1/data/raw/MICCAI-LH-BraTS2025-MET-Challenge-Training \
  --json_list ${PROJECT_ROOT}/work_space/S3/data/splits/s3_g2_fixed_split.json \
  --logdir ${PROJECT_ROOT}/work_space/S3/results/realonly/swin_unetr \
  --max_epochs 200 \
  --batch_size 1 \
  --val_every 10 \
  --out_channels 5 \
  --in_channels 4 \
  --roi_x 96 --roi_y 96 --roi_z 96 \
  --use_checkpoint \
  --gpu 0
```

## 9. 调参方式

Slurm 环境变量：

```bash
S3_MAX_EPOCHS=200
S3_BATCH_SIZE=1
S3_VAL_EVERY=10
S3_LR=1e-4
S3_WEIGHT_DECAY=1e-5
S3_WORKERS=8
S3_ROI_X=96
S3_ROI_Y=96
S3_ROI_Z=96
S3_FEATURE_SIZE=48
S3_USE_CHECKPOINT=true
```

显存不足时：

1. 先保持 `S3_BATCH_SIZE=1`。
2. 开启 `S3_USE_CHECKPOINT=true`。
3. 再考虑把 ROI 从 `96,96,96` 降到 `80,80,80`。
4. 如果 CPU/内存压力大，把 `S3_WORKERS` 降到 4 或 2。

## 10. 注意事项

1. S3 目前用的是普通 multi-class Swin UNETR，不是 nnU-Net。
2. S3 的指标包含 Dice 和小病灶 F1/AUC，但不是官方完整 lesion-wise evaluation。
3. real+synth 不能直接吃 G1 raw output；必须等 G2 accepted synthetic manifest 和物化后的训练入口。
4. internal locked test 不用于训练和调参。
