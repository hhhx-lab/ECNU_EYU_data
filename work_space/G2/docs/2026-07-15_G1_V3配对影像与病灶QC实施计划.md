# G1 V3 配对影像与病灶 QC Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 G1 V3 的 103 例完整 validation 上，用真实 T2W、生成 T2W 和真实 segmentation 完成可复核的影像级、区域级、连通病灶级质量评估，并为是否进入阶段 6 提供人工审批材料。

**Architecture:** G2 新增一个独立 CLI，逐例读取 G1 V3 `data/input/<case_id>/` 与阶段 5 `synthesized/`，先做几何和数值硬检查，再计算 whole/brain/tumor/标签/病灶指标，最后生成三平面配对图和批次汇总。服务器通过 CPU Slurm 调用同一个 CLI；冻结分割模型评估本轮不执行，最终由 real-only 与 real+V3 正式训练消融替代。

**Tech Stack:** Python 3.11、NumPy、NiBabel、SciPy、scikit-image、Matplotlib、stdlib unittest、Slurm。
