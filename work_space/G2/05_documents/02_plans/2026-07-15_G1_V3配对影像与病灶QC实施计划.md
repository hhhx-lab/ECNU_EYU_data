# G1 V3 配对影像与病灶 QC Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 G1 V3 的 103 例完整 validation 上，用真实 T2W、生成 T2W 和真实 segmentation 完成可复核的影像级、区域级、连通病灶级质量评估，并为是否进入阶段 6 提供人工审批材料。

**Architecture:** G2 新增独立 paired-QC CLI，逐例读取 G1 V3 `data/input/<case_id>/` 与阶段 5 `synthesized/`，先做几何和数值硬检查，再计算 whole/brain/tumor/标签/病灶指标，最后生成三平面配对图和批次汇总。另用冻结的 Dataset263 real-only S2 checkpoint，对真实 `t1n/t1c/t2f` 加生成 `t2w` 的同一 103 例做 teacher 推理，并与真实 T2W baseline 成对比较。teacher 只是阶段 6 辅助门，最终训练价值仍由 real-only 与 real+V3 正式训练消融决定。

**Tech Stack:** Python 3.11、NumPy、NiBabel、SciPy、scikit-image、Matplotlib、stdlib unittest、Slurm。
