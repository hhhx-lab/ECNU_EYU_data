# S4 服务器运行手册

更新日期：2026-07-12

## 1. 当前定位

S4 是 SAM2-UNet/SAM 变体探索线。正式可比实验必须读取 G2 case-folder fixed split；代码内原有 RC-stratified split 仅保留给独立探索 smoke，不作为 S1-S5 公平对比结果。

正式数据流：

```text
G2 approved data
  -> g2_materialize_nnunet_dataset.py case-folder view
  -> case_folders/train|val|test
  -> S4 --fixed_split_root
```

## 2. 环境

环境清单：

```text
work_space/S4/docs/S4_experiment.txt
```

## 3. 先由 G2 物化病例目录

从仓库根目录运行。real-only 示例：

```bash
python work_space/G2/code/g2_materialize_nnunet_dataset.py \
  --output-root /path/to/nnUNet_raw \
  --case-folder-root /path/to/g2_case_folders_realonly \
  --dataset-id 263 \
  --dataset-name BraTS2026_MET_S4_RealOnly \
  --dataset-profile real-only \
  --mode symlink
```

completion/real+synth 时重复传入对应 accepted manifest，具体命令见 `work_space/G2/docs/G2_G1适配执行清单.md`。

G2 输出：

```text
/path/to/g2_case_folders_realonly/
  train/<case_id>/<case_id>-t1n/t1c/t2w/t2f/seg.nii.gz
  val/<case_id>/<case_id>-t1n/t1c/t2w/t2f/seg.nii.gz
  test/<case_id>/<case_id>-t1n/t1c/t2w/t2f/seg.nii.gz
```

real-only 预期为 823 train、103 val、104 locked test。S4 只训练 train、用 val 选 checkpoint；test 不进入训练循环。

```bash
sbatch --export=ALL,\

PROJECT_DIR="${PROJECT_ROOT}/work_space/S4/code",\
```

`FIXED_SPLIT_ROOT` 是正式实验必填。只有探索性 smoke 才可不传该变量并使用 `TRAIN_DIR`，此时脚本会自行 RC-stratified split。

## 5. Slurm 预检

脚本会：

1. 激活指定环境。
2. 检查模型和训练脚本。
3. 检查 fixed root 的 `train/val/test` 三目录。
4. 导出 `SAM2UNET_FIXED_SPLIT_ROOT`。
5. 做 CUDA/import 自检。
6. 启动训练并写日志。

S4 Python 会再次检查：

1. 每例四模态和 seg 完整。
2. label 值域合法。
3. train/val/test case ID 无重叠。
4. locked test 不进入 DataLoader。

## 7. 调参

```text
SAM2UNET_EPOCHS=450
SAM2UNET_WARMUP_EPOCHS=30
SAM2UNET_CHECKPOINT_INTERVAL=10
SAM2UNET_BATCH_SIZE=1
SAM2UNET_ACCUMULATION_STEPS=1
SAM2UNET_CROP_SIZE=96,96,96
SAM2UNET_NUM_WORKERS=4
SAM2UNET_LR=1e-4
SAM2UNET_MAIN_HEAD_LR=1e-4
SAM2UNET_RC_HEAD_LR=3e-4
SAM2UNET_RC_LOSS_WEIGHT=4.0
SAM2UNET_RC_THRESHOLDS=0.15,0.20,0.25,0.30,0.35,0.40,0.50
```

显存不足时先保持 batch=1，依次尝试减小 crop、降低 worker。RC 结果差时先看 threshold sweep，再调 RC loss；不要同时改变 split。

```bash

```


debug 模式因病例 limit 数量会更小。

## 9. Real+synth 消融

1. 另起 dataset/case-folder root 和 SAVE_ROOT。
2. 只向 G2 fixed train 添加 accepted V2 augmentation。
3. V3 completion 按 master 原 split 替换 T2W。
4. val/test 身份保持不变。
5. real-only 和 real+synth 使用相同模型参数与训练预算。
6. 最终使用官方 lesionwise DSC/NSD 与 small-instance F1，不只看 S4 内部 Dice。

## 10. 停止条件

1. fixed root 缺任一 split 目录。
2. split ID 重叠。
3. label 越界或病例不完整。
4. locked test 被放进训练目录。
5. 直接读取未经 G2 accepted 的 G1 raw output。
6. real-only 与 real+synth 使用不同 fixed split。
