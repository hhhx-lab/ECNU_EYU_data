# 2026-10-13 审查反馈修复

本次修改针对 TumourDiffusion_1mm，未修改 S2 或 GliGAN 原目录，未启动真实数据训练。

## 五类修复

1. **数据失败返回成功**：预处理缺失、拒绝、异常病例均导致非零退出码；显式病例名单中找不到的病例写入报告；空任务和重复源病例直接失败。已有输出只有通过完成标记、配置/源/输出 SHA256、标签和网格验证后才复用。CSV 验证完整模态、标签、finite 和网格，失败不覆盖已有 CSV；成功后原子发布。评估端缺少指定模型、输入文件或完全没有指标也失败。
2. **划分泄漏**：训练、标签训练与评估默认要求 split，统一检查 train/val/test 的患者隔离。BraTS-MET-00001-000 与 -001 属于同患者。CSV 创建时将指定验证患者的所有访视一起划入 val；导出列表时先验证全部划分，再写文件。显式 all 模式只允许有意的全量处理，不绕过已有 split 的跨患者检查。
3. **步数多跑一次**：tumour 训练进入 batch 时先检查预算，成功更新后计数。num_steps=2 恰好两次更新；恢复后只执行剩余更新。AMP 溢出降低 scale 后重试同 batch，最多八次，跳过的更新不计步。旧 checkpoint 的历史更新次数无法反推，恢复时警告；新 checkpoint 带 step_semantics。标签训练的 iteration 保持“完成 epoch”含义，修复首尾多跑一轮及最终不保存。
4. **1 mm 坐标不一致**：实际采样和 affine 共用物理映射 `input=(output+0.5)*target_spacing/source_spacing-0.5`，保持裁剪前低侧体素边界。形状取整改变高侧视野边界，不改变 spacing。支持斜置 affine 和各向异性低分辨率轴最近邻；标签逐类别插值，不混合出非法类。输出记录 physical_spacing_v2。
5. **compile 恢复和 smoke 安全**：存储未包装模型权重，同时兼容旧 `_orig_mod.` 前缀；恢复 optimizer 和 AMP scaler，并拒绝已记录的架构、归一化、噪声配置不一致。smoke 移除所有递归删除，采用唯一工作目录及 checkpoint 目录，已有 WORK 拒绝执行，成功/失败均保留结果。移除可能因 head 提前关闭管道而中断评估的流程。

## 补充：训练启动脚本支持 1–4 张卡

`scripts/train_4gpu.sh` 不再要求恰好四张卡，取代上文"GPUS 数量不等于四时，在启动任何训练前返回 exit 2"一条。训练 Python 代码未改动。

- `GPUS` 中每个 ID 是一个并行槽位，四个模态轮流分配到各槽位；槽位之间并行，槽位内依次串行。默认 `"0 1 2 3"` 的行为与之前相同。
- `GPUS` 须有 1–4 个 ID，否则在启动任何训练前返回 2；同一 ID 可以重复（同一张卡上多个槽位）。
- 每个模态的退出码写入 `logs/train_<模态>.status`，启动前先清除上一次的状态文件。某个模态失败不影响同一槽位后续的模态；任一失败返回 1。
- 槽位进程忽略 SIGHUP 和 SIGPIPE、不依赖 errexit：终端断开或输出管道关闭后，仍会训练完队列里剩余的模态。原脚本四路同时启动，没有这个问题；串行队列需要这层保护。
- 网络宽度仍由 `--planner_gpu_gb 48` 固定，各种布局训练出的架构相同。

## 补充：评估噪声调度与 AdamW β₁

- **评估使用 checkpoint 记录的噪声调度**（`evaluate_generation.py`）。原先调度参数取自命令行（`--sigma_data` 默认 0.5），而网络结构取自 checkpoint；直接调用时漏传 `--sigma_data 1.0` 会用错误的预条件采样，且不报错。现在读取每个被评估模态的 checkpoint，调度以其记录为准，命令行值只用于旧 checkpoint 缺少的字段，被替换时打印提示；各模态调度不同时报错；`--sampling_method` 与调度不匹配时提前报错（原先 EDM 模型配 `ddim` 会在采样中途因缺少 betas 崩溃）；旧参数 `--beta_schedule` 只对没有记录调度的 checkpoint 生效；实际使用的调度和采样设置写入 `metrics.json` 的 `sampling`。`eval_checkpoints.py` 一直显式传入 `--sigma_data 1.0`，其已缓存的评估结果不受影响。
- **AdamW β₁ 默认由 0.5 改为 0.9**（`tumour_main_diffusion.py`，新增 `--adam_beta1`）。0.5 是 GAN 训练的惯例；同目录的标签扩散模型使用 0.9。值写进 checkpoint；续训以 checkpoint 中优化器状态里的 β₁ 为准（无新字段的旧 checkpoint 也能识别），与命令行不一致时报错并提示所需参数。续训此前的 checkpoint、或与 S2 现有模型严格对照时，加 `--adam_beta1 0.5`。两种设置的生成质量尚未在真实数据上比较。

验证：新增 6 项回归——评估调度 4 项单元测试（checkpoint 值替换命令行、各模态调度不一致报错、旧 checkpoint 保留命令行值、采样方法与调度的全部组合），以及 2 项 GPU 端到端测试（不传 `--sigma_data` 评估时 `metrics.json` 记录 1.0、EDM 配 `ddim` 被拒绝；新训练记录 β₁=0.9，去掉新字段的 β₁=0.5 checkpoint 不加参数续训被拒绝、加参数后续训成功）。在独立副本中分别关闭两处修复后，两项端到端测试均失败。
