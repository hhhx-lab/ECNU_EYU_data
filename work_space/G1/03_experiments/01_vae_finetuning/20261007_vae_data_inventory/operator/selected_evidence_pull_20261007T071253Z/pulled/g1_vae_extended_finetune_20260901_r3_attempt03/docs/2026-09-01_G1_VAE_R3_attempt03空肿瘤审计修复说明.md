# G1 VAE R3 attempt-03 空肿瘤审计修复说明

## 根因

attempt-02 扫描作业 `3554513` 完成了 823 个输入行的遍历，其中 807 例
审计成功，16 例原始分割全零。空间实现对全零分割返回
`lesion_support_audit=None` 是预期行为，因为不存在需要检查的肿瘤支持；
扫描器却无条件读取该对象的 `outside_voxel_count`，因此失败。

## 修复

扫描器新增显式双分支合同：

- 非空肿瘤必须在模型空间保持非空，且支持区域外体素为 0；
- 空肿瘤必须保持源/模型标签为空、源/模型肿瘤体素为 0，并记录
  `lesion_support_status=not_applicable_empty_source`。

attempt-03 验收要求全量 `823/823` 通过、`failure_count=0`，并要求恰有
16 行满足空肿瘤合同。历史失败病例 `BraTS-MET-01257-002` 仍必须在模型
空间保留非空二值肿瘤并集。

## 边界

本修复不改变训练数据、源标签、私有 binary-union 空间算法、VAE trainer
或预训练权重。所有产物保持 `experimental_unvalidated`，不能据此声称
固定 103 例、原生空间质量、下游分割收益或正式门禁通过。
