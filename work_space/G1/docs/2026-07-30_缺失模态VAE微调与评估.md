# 缺失模态 VAE 微调与评估

本文记录 G1 V3 缺失模态填补线里，VAE 微调方案和训练后评估的可复核路径。

## 方案入口

- 主手册：`work_space/G1/docs/G1_V3缺失模态服务器运行手册.md`
- 路线背景：`work_space/G1/docs/G1_G2_服务器训练推理QC运行手册.md`

## 微调方案要点

- 训练目标：`t1n + t1c + t2f -> t2w`
- 默认微调目录：`training/vae_finetuned/run_<jobid>/`
- 需要保留的产物：
  - `best_model.pt`
  - `baseline_metrics.csv`
  - `finetuned_metrics.csv`
  - `delta_metrics.csv`
  - `vae_selection.json`
  - `training_history.csv`
  - `finetune_config.json`
  - `quick_val_subjects.json`
  - `comparison_samples/*.png`

## 评估结果路径

- 103 例完整重建评估：`work_space/G1/results/v3_validation/run_3056246/evaluation_run.json`
- 103 例逐例指标：`work_space/G1/results/v3_validation/run_3056246/metrics.csv`
- 评估口径镜像：`work_space/G1/data/eval_metrics.csv`

## 训练后复核口径

- `evaluation_run.json` 记录了被验证的 VAE、EncDec、BBDM checkpoint 和 `bbdm_s`。
- 103 例评估结果以 `metrics.csv` 为准，路径和 subject 级结果都可直接复核。
- 仓库当前未镜像出独立的 `baseline_metrics.csv` / `finetuned_metrics.csv` / `delta_metrics.csv` 四件套；若要复盘微调选择，应回到训练树和 `evaluation_run.json` 中的权重路径。

## 备注

VAE 微调本体和 103 例评估是两步：
先在训练树里完成选择，再在 `run_3056246` 下保存完整体积评估结果。
