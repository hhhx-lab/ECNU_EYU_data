本文记录 G1 V3 缺失 T2W 填补线中，VAE 微调的实际实现、训练后比较、权重选择和当前证据状态。

## 1. 先澄清模型边界

最终缺失模态任务是：

```text
t1n + t1c + t2f -> t2w
```

但这不是 VAE 微调阶段的输入输出。VAE 阶段使用一个共享的四模态 Autoencoder，对每个模态分别执行自重建：

```text
t1n -> t1n 重建
t1c -> t1c 重建
t2w -> t2w 重建
t2f -> t2f 重建
```

VAE 负责建立稳定的图像到 latent 的编码/解码空间，并重点保护肿瘤区域。真正的缺失 T2W 条件生成发生在后续 EncDec/BBDM 阶段：使用 `t1n/t1c/t2f` 的 latent 生成 T2W latent，再由 VAE 解码为 T2W。

因此，不能把 VAE 微调描述成“三模态直接预测 T2W”。

## 4. VAE 微调的实际步骤

### 4.0 设计动机与方案选择

这套微调不是为了让 VAE 直接完成缺失 T2W 生成，而是为了先修正 latent 表征。MAISI VAE 在每个空间维度下采样 4 倍，`256x256x160` 的模型空间体积被压缩为约 `64x64x40` 的 latent；体积压缩比例为 64 倍。小转移灶在 latent 中只占很少体素，普通全体积平均重建损失容易被大量正常脑组织主导。

因此采用以下组合设计：

1. **全模型域适配**：encoder 和 decoder 一起微调，使编码端保留病灶信息的同时，解码端能够在 BraTS-MET 脑 MRI 域中恢复该信息。
2. **低学习率差异化更新**：encoder 使用 `2e-6`、decoder 使用 `1e-6`，在保留预训练初始化的前提下做小步适配。
3. **肿瘤感知 patch**：用较高概率围绕肿瘤训练，降低全体积训练的显存压力，并提高小病灶进入训练视野的频率。
4. **按连通域均匀采样**：先均匀选择一个 26-连接肿瘤连通域，再取其质心，避免大病灶仅因体素多而长期支配采样分布。
5. **肿瘤自适应加权**：根据 healthy/tumor 体素比提高肿瘤 MSE 权重，并截断到 `[3, 30]`，强化病灶重建但限制极端梯度。
6. **背景与 latent 双约束**：保留 whole MSE 和低权重 healthy MSE，防止只优化病灶而破坏整体脑结构；保留 `0.01 * KL`，限制 latent 分布过度漂移。
7. **独立验证选权重**：训练中的固定 20 例 quick validation 只负责选 `best_model.pt` 和早停；最终是否采用微调 VAE，仍由完整 103 例与预训练 VAE 的 paired 同口径比较决定。

其中第 1 至 7 项是方案设计目的；第 4.1 至 4.5 节记录对应的实际代码和默认执行参数。设计动机本身不等于效果已被证明，效果结论必须引用第 6 至第 8 节的评估证据。

### 4.1 初始化

1. 按 V3 的网络配置实例化 MONAI `AutoencoderKlMaisi`。
2. 加载预训练 VAE 的完整 encoder/decoder 权重。
3. 不冻结 encoder，也不冻结 decoder；两部分都参与反向传播。
4. encoder 与 decoder 使用差异化学习率：

```text
encoder: 2e-6
decoder: 1e-6
```

### 4.2 同步 patch 采样

每个 train 病例先在统一空间准备四个模态和 seg，然后采样一个 `128x128x96` patch。

- 80% 概率从 seg 的肿瘤前景中选择一个 26-连接肿瘤连通域，并以该连通域质心为中心。
- 20% 概率从脑区随机选择中心。
- 四个模态、seg、brain mask、tumor mask 和 healthy mask 使用完全相同的裁剪框。
- 裁剪框越过图像边界时进行零填充。
- patch 每个维度必须能被 4 整除，以匹配 VAE 的下采样比例。

脑区 mask 由四模态平均图像的强度阈值 `0.02` 得到；肿瘤 mask 为 `seg > 0`；healthy mask 为脑区减去肿瘤区。

### 4.3 前向与损失

每个 patch 的四个模态逐一进入同一个 VAE。训练时 latent 使用随机采样：

```text
z = mu + epsilon * sigma
```

重建损失为：

```text
loss = whole_MSE
     + 0.1 * healthy_MSE
     + lambda_tumor * tumor_MSE
     + 0.01 * KL
```

其中：

```text
lambda_tumor = clamp(healthy_voxel_count / tumor_voxel_count, 3, 30)
```

含义如下：

- `whole_MSE`：全 patch 重建误差。
- `tumor_MSE`：肿瘤 mask 内的重建误差，使用自适应权重强化小病灶。
- `healthy_MSE`：健康脑区误差，权重为 `0.1`，避免为了肿瘤过度破坏背景。
- `KL`：VAE 潜变量分布相对标准正态分布的约束。

### 4.4 优化器与训练控制

默认训练配置：

| 项目 | 默认值 |
|---|---:|
| optimizer | AdamW |
| weight decay | 0.0 |
| batch size | 2 个病例累积后更新 |
| 最大 epoch | 3 |
| AMP | BF16 |
| activation checkpointing | 关闭 |
| gradient clipping | 1.0 |
| scheduler | CosineAnnealingLR |
| scheduler 最低学习率 | `1e-7` |
| random seed | 42 |

每个 epoch 先打乱 train 病例顺序，再按 batch 取病例。一个 batch 内的每个病例都会处理四个模态，完成梯度累积后执行一次优化器更新。

### 4.5 Quick validation、best checkpoint 与早停

每个 epoch 在固定的 20 个 val 病例上验证，验证子集由 `seed + 10000` 确定性抽取，默认 seed 为 42。

验证时使用确定性的 `mu` 解码，不使用训练阶段的随机 latent 采样。若 quick-val 的 `tumor_MSE` 严格改善，则保存：

```text
best_model.pt
```

连续 2 次验证没有 tumor-MSE 改善时 early stop。每个保存周期还会生成：

```text
checkpoint_epoch<N>.pt
```

## 5. Slurm 执行顺序

`slurm/02_finetune_vae.slurm` 实际分三步执行：

1. 用原始预训练 VAE 在 val 上生成 baseline。
2. 使用 823 个 train 病例进行 patch 微调。
3. 加载 `best_model.pt`，在同一组完整 103 个 val 病例上与预训练 VAE 比较。

典型执行链由主手册提交：

```bash
VAE_JOB=$(sbatch --parsable --dependency=afterok:${ADOPT_JOB} \
  slurm/02_finetune_vae.slurm)
```

Slurm 脚本中的 `--skip_initial_validation` 只表示微调脚本不重复做初始 quick baseline；独立的 baseline 已在前一步 `validate_vae_recon.py --mode baseline` 完成，不能理解为跳过 baseline。

## 6. VAE 训练后评估

### 6.1 直接 VAE 比较

默认输出目录：

```text
training/vae_finetuned/run_<jobid>/
```

按当前评估代码，一次完整的 VAE 直接比较应生成并保留以下产物。这是输出合同，不代表这些文件已经进入 GitHub：

```text
best_model.pt

finetuned_metrics.csv
delta_metrics.csv

training_history.csv

quick_val_subjects.json
comparison_samples/*.png
```

103 个 val 病例乘以 4 个模态，应产生 412 行逐模态结果。直接比较的指标包括：

- `whole_SSIM`
- `whole_MSE`
- `tumor_SSIM`
- `tumor_MSE`
- `healthy_SSIM`
- `healthy_MSE`
- `KL`

`delta_metrics.csv` 中的 delta 定义为：

```text
fine-tuned - pretrained
```

当前实现中的 `tumor_SSIM` 和 `healthy_SSIM` 是对应 mask 周围紧致 ROI 的 SSIM，不是把 mask 外体素全部置零后的严格 mask-only SSIM；`tumor_MSE` 和 `healthy_MSE` 则是 mask 内的 MSE。

### 6.2 评估空间边界：不是恢复到原生 NIfTI 空间后计算

微调前后 VAE 的直接比较使用同一套预处理合同：每个病例先由 `prepare_subject_space` 完成 robust normalization、前景居中和各向同性重采样，得到固定 `256x256x160` 的模型空间体积；预训练 VAE 和微调 VAE 都在该模型空间中自重建，并直接与同一模型空间 target 计算 SSIM/MSE。

`validate_vae_recon.py` 没有调用 `restore_to_native()`。因此，三张表支持的严格结论是：

> 微调 VAE 在相同归一化模型空间预处理合同下，改善了四模态自重建的肿瘤区域表现，并满足当时的自动选择门限。

不能把这三张表表述为“恢复到病例原始 shape/affine 后的重建质量提升”。原生 NIfTI 空间恢复存在于后续完整 T2W 生成评估 `evaluate.py` 中，那一阶段会调用 `restore_to_native()`，属于另一份评估合同。若论文需要单独声称 VAE 在原生空间优于预训练版本，必须新增一轮 paired native-space 评估。

### 6.3 自动选择条件

只有同时满足以下条件，才选择微调 VAE：

```text
mean(delta_tumor_SSIM) >= 0.03
mean(delta_whole_SSIM) >= -0.005
```

否则保留原始预训练 VAE：

```json
{
  "decision": "keep_pretrained",
  "selected_weights": ".../autoencoder_epoch273.pt"
}
```

注意：当前实现对 412 行、四个模态的结果求平均，选择条件不是只针对 T2W 计算。若项目要求只用 T2W 选择 VAE，需要另行修改评估口径，不能把当前结果解释成 T2W-only 门禁。

自动选择后还必须人工查看 5 个 tumor-SSIM 退化最严重的病例图，检查：

- 图像是否错位；
- 是否出现空白或截断；
- 是否出现明显过度平滑；
- 肿瘤区域是否被破坏。

### 6.4 进入后续生成训练

VAE 通过选择后，使用 `vae_selection.json` 中的 `selected_weights` 统一编码全部 1030 个完整病例，然后生成：

- 4120 个模态 latent；
- 1030 个空间变换记录；
- 1030 个 attention mask；
- 1030 个 lesion-weight mask。

之后才训练 EncDec 和 BBDM。最终 265 个缺 T2W 病例的推理会加载阶段 5 已冻结的 VAE、EncDec 和 BBDM 权重。

```text

  -> 103 例、四模态、412 行直接比较
```
