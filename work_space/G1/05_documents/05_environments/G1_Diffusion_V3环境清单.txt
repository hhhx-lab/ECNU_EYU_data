G1 Diffusion augmentation V3 环境清单
=====================================

适用代码：
work_space/G1/code/BraTS_2023_2024_solutions-main 3/Segmentation_Tasks/GliGAN

一、NYU Greene 正式环境
1. 调度系统：Slurm（Greene）。
2. 账号：torch_pr_522_general。
3. 正式训练：单节点 4 GPU（#SBATCH --gres=gpu:4）。
4. 数据准备：CPU 作业（无 GPU）。
5. Conda 安装：/share/apps/anaconda3/2025.06
6. 环境名默认：g1_diffusion_v3（可用 CONDA_ENV 覆盖为 brats / g1_diffusion_v2）。
7. 项目根默认：/scratch/bf2260/ECNU_EYU_data
8. 运行根默认：/scratch/bf2260/ECNU_EYU_data/runs/g1_diffusion_v3
9. 日志默认：/scratch/bf2260/ECNU_EYU_data/logs
10. 邮件：bf2260@nyu.edu

二、运行时核心包
1. torch，必须能访问 CUDA。
2. monai。
3. nibabel。
4. numpy < 2.0。
5. scipy。
6. pandas。
7. matplotlib。

三、固定启动方式
脚本内：
source /share/apps/anaconda3/2025.06/etc/profile.d/conda.sh
conda activate ${CONDA_ENV:-g1_diffusion_v3}

不在 Slurm 作业中安装包，不使用 sudo pip，不混用系统 Python。

四、torch.compile
NYU 默认 USE_COMPILE=1。
若 Triton / 编译失败，提交时覆盖：
USE_COMPILE=0 sbatch slurm/02_train_4modal_v3_nyu.slurm

当前加速方式：AMP、TF32、cuDNN benchmark，以及四模态四卡同节点并行。

五、验收命令
sbatch slurm/00_smoke_v3_nyu.slurm
sbatch slurm/00_preflight_crop64_v3_nyu.slurm

日志必须分别出现：
SMOKE_TEST_PASS
CROP64_BATCH4_EAGER_PASS

ECNU 曾用 segmamba + a100 array 单卡任务验证过 GPU smoke 与 64^3/batch=4 预检；
当前正式入口已改为 NYU Greene，不再维护 *_v3_ecnu.slurm。
