S2 fixed-split experiment environment
=====================================

默认正式模式
------------
S2_EXPERIMENT_MODE=current
Dataset263_BraTS2026_MET_RealOnly_Current
823 train / 103 validation / 104 internal test
不使用交叉验证；fold_0 只用于 nnU-Net API/目录兼容。

环境
----
CONDA_SH=/share/apps/anaconda3/2025.06/etc/profile.d/conda.sh
CONDA_ENV=brats2026_s2
已在 Python 3.10、PyTorch 2.7.1、nnunetv2 2.8.0、batchgenerators 0.25.3、batchgeneratorsv2 0.3.3 上完成 trainer 导入和 CLI 参数验证。
Python 用户态依赖见 repository/requirements.txt。PyTorch 必须使用与服务器 CUDA/driver 兼容的构建，不要为了对齐 requirements 盲目覆盖已能正常识别 GPU 的 PyTorch。
不要使用 sudo pip，不要混用系统 Python。

入口
----
准备：work_space/G1/code/brats2025-latent-ensemble-synthesis-main/slurm/04_s2_realonly_prepare_nyu.slurm
训练：work_space/G1/code/brats2025-latent-ensemble-synthesis-main/slurm/04_s2_realonly_nyu.slurm
验证：work_space/G1/code/brats2025-latent-ensemble-synthesis-main/slurm/04_s2_realonly_official_eval_nyu.slurm
推理：work_space/G1/code/brats2025-latent-ensemble-synthesis-main/slurm/04_s2_realonly_infer_nyu.slurm

运行
----
PREP_JOB=$(sbatch --parsable --export=ALL,S2_EXPERIMENT_MODE=current work_space/G1/code/brats2025-latent-ensemble-synthesis-main/slurm/04_s2_realonly_prepare_nyu.slurm)
sbatch --dependency=afterok:${PREP_JOB} --export=ALL,S2_EXPERIMENT_MODE=current work_space/G1/code/brats2025-latent-ensemble-synthesis-main/slurm/04_s2_realonly_nyu.slurm
