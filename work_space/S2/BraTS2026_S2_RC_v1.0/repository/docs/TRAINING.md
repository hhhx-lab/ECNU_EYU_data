## Modifications

### Deterministic five-fold split

The completed fixed validation split is preserved as fold 0. The original fold-0
training set is partitioned deterministically into the validation sets for folds
1-4. Every train+validation case appears in validation exactly once, while the
internal locked test remains excluded from all folds.

Per fold for the current 1035-case CV pool:

Training:

828 cases

Validation:

207 cases

Internal locked test:

259 cases, not materialized into the training dataset

No overlap exists within a fold. Split files are generated by
`scripts/04_build_five_fold_splits.py`.

---

### RC loss weighting

Cross-entropy weights:

[1, 1, 1, 1, 3]

The RC class receives a weight of 3.

---

### Epochs

Training duration:

1000 epochs

## Training command

Recommended server submission:

```bash
PROJECT_ROOT=/scratch/bf2260/ECNU_EYU_data
cd ${PROJECT_ROOT}
mkdir -p logs

PREP_JOB=$(sbatch --parsable \
  work_space/G1/code/brats2025-latent-ensemble-synthesis-main/slurm/04_s2_realonly_prepare_nyu.slurm)

sbatch --dependency=afterok:${PREP_JOB} --array=1-4%4 \
  work_space/G1/code/brats2025-latent-ensemble-synthesis-main/slurm/04_s2_realonly_nyu.slurm
```

For the current continuation run, the preparation job reuses
`work_space/G2/results/manifests/nnunet_case_mapping_realonly.csv`,
`work_space/G2/results/splits/splits_final_train_val_test.json`, and the
Dataset260 preprocessing used by completed fold 0. It creates the five-fold
split files without rematerializing Dataset260. Keep `G2_REFRESH_REALONLY=0`;
refreshing is only valid for a new experiment that retrains folds 0-4. The
training array never modifies or preprocesses Dataset260.

Manual command after conversion and preprocessing:

```bash
nnUNetv2_plan_and_preprocess -d 260 --verify_dataset_integrity
S2_FOLD=1 bash train.sh
```

`train.sh` copies the custom trainer into the active nnU-Net environment, reads `S2_FOLD`, skips an existing final checkpoint, resumes an existing latest checkpoint, and starts a new fold from scratch when no checkpoint exists.
