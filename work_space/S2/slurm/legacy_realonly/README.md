# Dataset263 real-only NYU jobs

This directory preserves the four NYU Greene jobs used to prepare, train,
evaluate, and infer the Dataset263 real-only baseline. That baseline is the
warm-start source for the later Dataset264 completion experiments.

These scripts remain reproducibility artifacts for the completed upstream
stage. New Dataset264 completion, ablation, MET-AUG, and H20 runs use the jobs
directly under `work_space/S2/slurm/`.
