# ⓪ 贯穿性发现：增强管线在结构上稀释 RC

按现行约束（`core ≥27 mm³`、`bbox ≤56 mm`）筛 Table 7：单纯 RC(42, 中位 154)、ET+RC(15, 中位 1,369) 可用；SNFH+ET+RC(107, 中位 30,813) 临界；SNFH+RC(25)、NETC+SNFH+ET+RC(19) 因 bbox 超限基本不可用。

**可用 RC 供体约 57–100 个（0.6–1.1%），不到自然占比 2.3% 的一半。**而 ET 出现在 96.6%、SNFH 出现在 46.5% 的病灶中——任何加合成灶的路线都按 96.6 / 46.5 / 0.6 的比例注入三类，系统性推离 RC 先验。

对应观测：B(−0.077)、F(−0.051)、E-SNFH(−0.046)、C40(−0.033) 全部损失 RC，唯一为正的 D(+0.077) 恰是唯一"多放一个完整供体"的路线。**这是共用供体采样层的缺陷，不是单条路线的参数问题。**

# 第一部分 · 逐路线审计

## B — 按核心体积的受控缩放

`ET +0.017 / RC −0.077(最差) / TC +0.020 / WT −0.002`；被 E-SNFH 四区严格支配；epoch 125 稳定

| | 改进 | 依据 |
|---|---|---|
| **B①** | **含 RC 供体豁免缩放** | Table 7：四个 RC 表型中位体积 1,369–118,281，**166/208 (80%) 落进 `>500` 档被强制缩到 15–60%** |
| **B②** | **相对比例 → 表型条件绝对体积采样**，校验从"非空"升级为**类别占比容差** | `>500` 档含 2,559 个、跨三个数量级同一规则，`27/V` 在 V>180 后失效；Table 7 尺寸-组成单调耦合 27→307→4,966→30,813→118,281 被 B 破坏；Table 4 填充率中位 0.48，薄壳会被下采样腐蚀而"非空"仍通过 |

### B① 详述

在缩放入口加一个前置分支：供体含 label 4 时，尺度直接置 1.0，**跳过全部分档与重抽逻辑**，直接进入放置。结果码记 `B_RC_EXEMPT`。

- **冻结值**：无参数。
- **校验**：含 RC 的合成灶，其实际体积必须逐条等于供体体积（无重采样发生）。
- **报告**：含 RC 合成灶的体积直方图须与其供体体积直方图完全重合——不重合即说明分支未生效。

### B② 详述

取消原有的三个体积档与相对比例 `r_v` 抽样。改为：读取供体表型 → 取该表型的体积经验分布 → **先按可行区间截断该分布，再抽目标体积** → 由目标体积与供体体积之比开立方得线性尺度 → 最近邻重采样 → 校验。先截断再抽是为了避免大量空转重抽。

- **冻结值**：线性尺度限制在 **1/1.5 ~ 1.5**（等价体积比 0.296–3.375）；重抽上限 **5 次**；类别占比容差 **25%**。
- **校验**（四项全过才接受）：标签集合仍属 {0,1,2,3,4}；供体中存在的每个类别在缩放后仍非空，**且其占最终 support 的体素比例相对缩放前变化不超过 25%**；核心体积 ≥27 mm³；bbox 最大维 ≤56 mm。
- **失败处理**：重抽耗尽记 `B_SCALE_NO_OP`，**退回 s=1.0 原样平移并记录**。严禁"钳回原体积"后伪装成一次成功缩放。
- **报告**：实际尺度分布；表型×体积联合分布对照 Table 7；`B_SCALE_NO_OP` 率按表型分解。

## C — 合成频率剂量

`ET +0.027 / RC −0.033 / TC +0.012 / WT −0.044`；**小病灶 F1 崩至 WT 0.0905**（基座 0.333）、FN 最高、FP 最低；**epoch 50 达峰后退化**

| | 改进 | 依据 |
|---|---|---|
| **C①** | **统一剂量采样器 + 网格向下探至 C-10 / C-20** | C-20 即 A 基线、C-40 已灾难性退化，向上无意义；Table 1 病灶数 IQR 1–8、max 312 ⇒ 同一 `p_select` 在孤立转移(24.1%)与 48 灶患者间产生的合成占比差两个数量级 |
| **C②** | **合成剂量退火** | C/D 于 epoch 50 达峰后退化，B/E/F 稳定至 175；C40 呈 FP↓+FN↑+小灶崩三者同向 = 离流形样本充当标签噪声 |

### C① 详述

关键架构决定：C 与 F 在现行定义下**不是独立变量**，必须实现为同一个采样器。该采样器的生效概率为「λ × 负荷权重 w(N) × 基准概率」并截断于上限；**C 是 w(N)≡1、λ=1 的特例，F 是 w(N) 取自经验分箱的情形**。这样二者的对照才成立。

- **冻结值**：基准概率网格 **{0.10, 0.20}**。**不再运行 0.40 / 0.60。**
- **强制仪表**：每 epoch 汇总「提交的合成灶总数 ÷ 受体病例的真实病灶总数」，记为实际剂量比；同时**分别报告选中率与实际提交率**（二者不可混用）。
- **判定口径**：所有横评一律以实际剂量比为横轴，而非配置上的基准概率——否则两条路线的"同剂量"只是名义上的。

### C② 详述

按预算的**前 2/3 保持基准剂量，后 1/3 线性衰减至 0**。预算 125 时，约在 epoch 83 开始衰减。动机是：C/D 的收益在早期就已兑现（峰值出现在预算的 40% 处），后期继续注入合成材料只带来噪声。

- **冻结值**：保持段占比 **2/3**，衰减为线性；候选集维持 {25,50,75,100,125}。
- **报告**：逐 epoch 的生效概率与实际剂量比曲线，与内部 EMA fg dice 曲线叠加——**这是确认峰值是否被后移的唯一证据**。

## D — 第二个独立病灶

`ET −0.023 / RC +0.077(唯一为正) / TC −0.024 / WT −0.059`；**小病灶 F1 最高、唯一非零 small-RC、FN 最低**；**FP 全区最差**；epoch 50 达峰

| | 改进 | 依据 |
|---|---|---|
| **D①** | **按患者内真实秩结构生成**：尺寸从名次条件分布抽、放置距离从经验最近邻分布抽 | **Table 9 秩衰减 rank1 10,587 → rank2 787 → rank3 317 → rank8 65**，而现行两灶从同一边缘分布抽取；Table 8 真实 NN 距离 IQR **16.1–47.5**、中位 28.0 mm，而现行只有 ≥5 mm 下限、无典型性约束 |
| **D②** | **剂量退火** | epoch 50 达峰后退化 |

### D① 详述

**尺寸**：合成灶应落在卫星位而非索引灶位。目标名次取「受体现有病灶数 + 本灶序号」，下限 2、上限 8，再从该名次的体积经验分布抽目标体积。受体已有 3 个病灶时，第一个合成灶按 rank-4（中位 194 体素）、第二个按 rank-5（中位 141）抽——而不是像现在这样两个都从中位 99 的边缘分布抽。

**放置**：从经验最近邻距离分布（截断于 ≥5 mm）抽一个距离，随机选一个已有病灶的质心作锚点，沿随机方向偏移该距离得候选中心，再校验：距所有已有标签 ≥5 mm、距脑边界 ≥3 mm、bbox ≤56 mm。重抽上限 **10 次**，耗尽记 `PLACEMENT_NO_OP`。

- **冻结值**：`p_second = 0.20`、`max_tumours = 2`、放置重抽 10 次、名次上限 8。
- **失败处理**：`SECOND_NO_OP` 只丢弃第二灶，**不回滚已完整提交的第一灶**，也不留第二灶的任何部分结果。不进入三灶。
- **⚠️ 归因说明**：秩条件尺寸应实现为共享采样器的开关（默认关闭），D\* 打开它意味着 D\* 相对旧 D 改了**两件事**。若需严格单变量归因，须跑「D + 秩条件」与「D + 边缘分布」两个 arm。
- **报告**：最终 0/1/2 灶比例（不是配置上的 `p_second`）；合成灶体积分布对照 rank-2 经验分布；放置距离分布对照 Table 8。

### D② 详述

参数与 C② 完全一致，作为可挂载到任意路线的独立开关。D 的早熟退化是本项的直接动机，**其效果由「峰值是否从 epoch 50 后移」判定**，而非由最终指标判定。

## E-SNFH — 纯 ET 供体外加 1 mm 壳

**`ET +0.037 / TC +0.035 / WT +0.032` 全场最佳**，NSD/HD95 亦最佳；但 `RC −0.046`、小病灶 F1 低于基座、FN 3.252 > 基座 2.913；稳定且 175 仍在改善

| | 改进 | 依据 |
|---|---|---|
| **E①** | **壳厚随核心尺寸缩放 + 体积门控** | Table 7：**纯 ET 中位 27 体素 vs SNFH+ET 中位 307，比值 ≈11.4×**。现行固定 1 mm 壳对 27 体素供体（等效半径 1.86 mm）产生 3.6× 体积增量，对 5,000 体素供体（等效半径 10.6 mm）仅 1.3× |
| **E②** | **构造上限从 10% 提至接近真实条件比例**（必须在 E① 之后） | 真实 `P(SNFH+ET ｜ ET 类)` = 2,380/(4,569+2,380) = **34.3%**，现行 10% 过度保守 |

### E① 详述

**壳厚**：不再使用固定 1 mm。由供体核心体积换算等效球半径，壳半径取「系数 × 核心等效半径」，系数由 train-only 的「SNFH+ET 中位体积 ÷ 纯 ET 中位体积」开立方减一反解（Table 7 的 307/27 对应系数 ≈1.25，实际取 train-only 重算值）。壳半径下限 1 mm（1 mm spacing 下的可表示下限）、上限 10 mm（防止大供体产生荒谬壳厚）。**形态学核仍必须是物理球，不得用立方体近似。**

**体积门控**：构造完成后，若结果体积不落在 train-only 的 SNFH+ET 体积分布的 p10–p90 区间内，则拒绝构造。这保证构造产物落在真实 SNFH+ET 流形内；实践上它会把 E-SNFH 自动限制到合适尺寸的供体上，无需再单独设尺寸门槛。

- **失败处理**：拒绝时记 `E_TOPOLOGY_FALLBACK` 并**退回该供体的真实未构造标签**，绝不输出畸形标签。若 fallback 率 >30%，E 不具可解释性，停止进入 Gate 3。
- **⚠️ 诚实说明**：**E-SNFH 损伤小病灶检测的机制尚未确认。**按上面的数字，现行 1 mm 壳对小供体的膨胀倍数（3.6×）反而比对大供体（1.3×）更接近真实比值（11.4×）。本项修正的确凿依据是**跨尺度不一致**，不是"过度膨胀小灶"。真实机制须由 X4 的产出分布报告确认后再定论——**这正是 X4 排在第一位的原因**。

### E② 详述

上限实现为「对最终**提交**的合成灶的配额」，而非对尝试次数的配额；超配额时该次构造退回未构造标签并记 `E_QUOTA_SKIP`。

- **冻结值**：分三阶段推进 **0.10 → 0.20 → 0.34**，每阶段须通过 §0 的判定规则才可进入下一阶段。
- **前置**：**必须在 E① 落地之后**——在错误的构造上提高配额等于放大错误。
- **报告**：实际达成的构造占比 vs 配置配额；构造灶与非构造灶的体积分布对比。

## F — 保持总剂量的自适应频率分配

`ET +0.022 / RC −0.051 / TC +0.031 / WT +0.015`；次优；稳定，175 时小灶 F1 显著改善（+0.033/+0.032, p=0.0024/0.0052）

| | 改进 | 依据 |
|---|---|---|
| **F①** | **用本统计完成前置检验并冻结 w(N)** | 规范要求执行 F 前须验证病灶负荷与小核心比例的关系、否则跳过 F。**Table 9 的 rank 4–8 中位仅 194/141/105/82/65——高负荷患者确实携带更多小卫星灶**，方向可据此冻结 |
| **F②** | **与 C 统一剂量定义** | F 定义为"总剂量固定为 C 最佳值时改变分配"，而 C 的剂量是 per-patch 概率、本身已隐含负荷依赖；不统一则二者不是独立变量 |

### F① 详述

**分箱**：按 Table 1 的天然分位切 N：`1`（占 24.1%）、`2–3`（至 p50）、`4–8`（至 p75）、`9–16`（至 p90）、`17–24`（至 p95）、`>24`。

**权重**：每个分箱的权重取「该箱内各患者『小于 27 mm³ 的病灶数 ÷ 总病灶数』的均值」，再在训练集患者分布上归一化使期望为 1。**冻结前必须检查权重随 N 单调递增**；若非单调或置信区间跨越，按规范**跳过 F**。

**上限与配平**：生效概率上限设为基准概率的 **3 倍**；配平系数 λ 用二分法在训练集患者分布上求解，使截断后的期望生效概率与基准概率的偏差小于 1e-4。

- **纪律**：分箱、方向、上限三者在 Gate 1 前写入配置，**禁止看完验证结果再切换"病灶多升概率／降概率"方向**。
- **报告**：实际达成的期望生效概率与基准的偏差；各分箱的实际提交率。

### F② 详述

F 的 arm 与其对照 C arm 必须使用**同一个实际剂量比**（偏差 <5%），而非同一个基准概率。这是 F 能否通过判定的**前提条件，在 Gate 1 校验**——若两者实际剂量比不等，F 与 C 的差异里混着剂量，对照无效。

F 只重分配**频率**未重分配**尺寸**，而 Table 9 表明二者联合结构化——此为新变量，**不并进 F**，另立为 G（排序表第 12 位）。

| | 内容 | 依据 | 成本 |

### X1 详述

两阶段采样：先以目标比例决定本次是否要 RC 供体，再在对应子池中抽。目标比例冻结为 **0.023**（匹配自然占比，不引入新倾斜）。**RC 供体的 bbox 上限放宽至 80 mm**（其余供体维持 56 mm）——80 mm 仍可放入 128×128×96 的 patch，且 Table 5 显示 >80 mm 的病灶仅 3.6%。放宽后可用 RC 供体预计从约 57 增至约 164（纳入 SNFH+ET+RC 的多数），但仍需显式配额才能达到 2.3%。放置时须保证整个 bbox 在脑内且 clearance ≥3 mm。RC 子池重抽 5 次仍失败，记 `RC_QUOTA_NO_OP` 后降级为普通采样——**不得静默降级**。

- **报告**：实际 RC 合成灶占比、`RC_QUOTA_NO_OP` 率、RC 合成灶的表型分解。

### X2 详述

同 C②，实现为可挂到任意路线的独立布尔开关。

### X3 详述

**独立 Gate，禁止与任何其他改动同跑。**

**前置 smoke**（必须先单独通过）：三个子档 `8–12 / 13–19 / 20–26` 体素各 8 例、共 24 个固定 seed 样本，montage 并排显示「供体标签 ｜ 构造标签 ｜ 四模态结果 ｜ 最终 seg」，人工 **24/24** 接受方可进入训练；靠 fallback 获得的样本不计入。

**该尺度的额外约束**（因几何校验在此尺度变得边缘）：重采样后连通体素数 ≥8；构造后必须仍是**单连通分量**（不得裂成多块）；脑内 clearance ≥3 mm、病灶间 clearance ≥5 mm 维持不变。

- **冻结值**：新地板 `core_volume_mm3 ≥ 8`。

### X4 详述

输入为 §0 的运行时日志，对已有五路各跑一次即可。四张对照 + 两项汇总：

| # | 对照内容 | 参照 | 统计量 |
|---|---|---|---|
| 1 | 合成灶体积直方图，按 `1–10/11–50/51–200/201–500/501–1k/1k–5k/5k–20k/>20k` 分档 | Table 2 的 1194/2347/1984/1034/564/838/480/677 | χ² 拟合优度 |
| 2 | 表型 × 体积联合分布 | Table 7 的 12 种模式计数与中位体积 | 按表型对 log 体积做 KS |
| 3 | 放置距离分布 | Table 8（p5 6.0 / p25 16.1 / p50 28.0 / p75 47.5 / p95 96.6） | KS |
| 4 | 每例合成灶数分布 | Table 1（p50 3 / p75 8 / p90 16 / p95 24） | χ² |
| 5 | 各失败码计数与占比 | — | — |
| 6 | 选中率 vs 实际提交率 vs 实际剂量比 | — | — |

- **用途**：很可能直接证实或证伪 B①/D①/E① 三条诊断，从而省掉后续若干次训练。

# 第二部分 · 组合方案

约束：**(a) 不并置两个"加量"变量**（C/D 皆早熟）；**(b) epoch 达峰须相容**；**(c) 先挂 X1**；**(d) 判定用 §0 规则**。

| 代号 | 组成 | 逻辑 | 风险 |
|---|---|---|---|
| **K1** | E-SNFH\* + F\* + X1 | 两条唯一非回退路线；均"不加量"、均稳定至 175、epoch 相容；X1 抵消共同的 RC 损失 | X1 失效则 RC 复合损失可达 −0.097 |
| **K2** | E-SNFH\* + D\* + X1 + X2 | **唯一覆盖两个 Pareto 角**——E 独占 ET/TC/WT，D 独占 RC 与小灶 F1 | epoch 冲突（E 峰 125+，D 峰 50）；X2 能否后移 D 的峰未知 |
| **K4** | X3 + E-SNFH\* | **唯一可能真正提升小病灶 F1 的组合** | 扩散模型在 8–27 体素尺度保真度未验证 |
| **K5** | K1 + D\* | 用 D 补 K1 的 RC 塌陷 | 条件触发：K1 与 K2 均为正才可归因 |

### K1 详述

**配置**：供体采样开 X1（RC 配额 0.023、RC bbox 上限 80 mm）；缩放开 B①+B②；构造用 E①（系数由 train-only 反解、门控用 SNFH+ET 的 p10–p90），**配额先维持在阶段 1 的 0.10**；剂量用 F① 的经验分箱权重。**退火关闭**（E/F 本就稳定，开退火会引入第三个变量）。

- **对照 arm**：现有的 E-SNFH125 与 F125。
- **判定重点**：RC Dice 是否回到原 E 的 0.377 附近——这是 X1 是否生效的直接检验。

### K2 详述

**配置**：供体采样开 X1；缩放开 B①+B②；尺寸模式设为秩条件、放置用经验 NN 距离；第二灶 `p_second=0.20`、`max_tumours=2`；构造用 E①；**退火打开**（保持段 2/3）。

- **对照 arm**：E-SNFH125 与单路 D\*。
- **必须逐 epoch 报告 EMA 曲线**——本组合的首要风险是 E 与 D 的峰值位置不相容，而单一 checkpoint 选择无法同时照顾两者。若曲线显示峰值仍在 50 附近，说明 X2 未能后移 D 的峰，此时应先回到单路 D\* 调退火参数，而不是继续调组合。

### K4 详述

**配置**：核心体积地板降至 8（**前置 24/24 smoke 必须已通过**）；构造用 E①；**剂量用 C 配置（权重恒等 1）**以减少同时变动的变量数。主要终点切换为 **WT 小病灶 F1**（§0 判定规则的 X3 分支）。

这是唯一能让终点真正移动的组合，但也是唯一同时改动"可生成尺寸范围"与"构造方式"的组合——若失败，须先单独跑 X3（不带 E）以定位原因。

### K5 详述

仅当 K1 与 K2 **均**通过判定时运行。否则三个变量同动，结果不可归因。

### 明确排除

含 C-40/C-60 者（早熟会传染稳定路线）；**D + F**（规范刻意分离的两变量，可归因性最差）；含未修正 B 者；**E-COMB**（前置 E-NETC 从未运行）。

## 执行顺序

**第 0 步**：落地 §0（供体清单、派生分布、运行时日志）。这是所有方案的硬依赖，且日志不落地则 X4 无法执行。

**第 1 步**：排名 1–4。一次零成本报告 + 三次单变量训练，全为配置级改动，全部直接检验一条已写明机制的诊断。

**第 2 步**：据 X4 结果决定 K1/K2 的参数（尤其 D 的峰值是否被 X2 后移），再冻结组合配置。**现在不必冻结。**

## 口径提醒

上述排序以四区 Dice 与 0908/0914 检测指标为准。**除排名 8、9 外，其余方案都不可能改善评测口径下的小病灶 F1**——27 mm³ 地板在结构上排除了那个类别。若小病灶 F1 仍是主要终点，X3 的实际优先级应高于表中位置；若主要终点已转为整体分割质量，当前排序适用。
