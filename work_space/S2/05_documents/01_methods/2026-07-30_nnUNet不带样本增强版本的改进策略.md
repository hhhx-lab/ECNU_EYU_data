# nnUNet 不带样本增强版本的改进策略

本文记录 S2 **不使用在线 MET-AUG** 路线的改进矩阵、最终选型和结果路径。Dataset264
仍包含 212 个离线缺失模态补全训练病例，因此不能把 B/E 称为“完全无样本增强”。

> **证据绑定纠正（2026-08-14）**：旧汇总把 Dataset263 real-only 指标误标成 B。
> 下文已恢复真实身份；原始 CSV、Panoptica JSON 和 checkpoint 均未改写。

## 评估范围

- 数据集：`Dataset264_BraTS2026_MET_Completion`
- 固定划分：`1035 train / 103 val / 104 locked test`
- 固定验证：`103` 例

## 改进矩阵

- `B`：`nnUNetTrainerBraTS2026RCCompletionFineTune`
- `A-1`：仅改架构
- `E`：`nnUNetTrainerBraTS2026RCFocalCompletionFineTune`
- `A-1+E`：架构 + Focal

## 结果路径

- 冻结选择：`work_space/S2/results/s2_small_lesion_ablation_20260721/checkpoint_selection.json`
- 总结比较：`work_space/S2/results/s2_small_lesion_ablation_20260721/final_comparison_20260724.md`
- 风险复核：`work_space/S2/results/s2_small_lesion_ablation_20260721/risk_review_20260724.md`
- real-only（R）内部评估：`work_space/S2/results/s2_eval_results/leaderboard_metrics.csv`
- completion 普通 loss（B）内部评估：`work_space/S2/results/s2_completion_dataset264_t2w_20260720/official_style_eval/leaderboard_metrics.csv`
- completion Focal（E）内部评估：`work_space/S2/results/s2_small_lesion_ablation_20260724_official_eval_retry_numpy126/focal/leaderboard_metrics.csv`

## 关键结论

- 总体保守基线：`B`
- 小病灶后续基座：`E`
- `A-1` 不选，`A-1+E` 也不选

## 选型理由

- 四个 Dataset264 候选中，`B` 的 WT DSC/NSD/all-instance F1 最高，分别为
  `0.593539/0.593146/0.723753`
- `E` 的 WT small-instance F1 相对 B 从 `0.330570` 小幅提升到 `0.333083`
- `E` 的 RC DSC/NSD/F1 相对 B 从 `0.235939/0.212300/0.155556` 提升到
  `0.377022/0.273118/0.421053`，RC FP 从 `0.679612` 降至 `0.038835`
- `A-1` 与 `A-1+E` 都存在总体指标退化或 FP 增大问题
