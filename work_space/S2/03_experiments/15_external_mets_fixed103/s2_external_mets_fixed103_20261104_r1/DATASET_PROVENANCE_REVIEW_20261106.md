# 去年METS数据入口与当前横评的训练重叠风险

复核UTC：2026-11-06T13:06:51Z；北京时间21:06:51。目的：回应用户对外部模型高分及数据泄露的疑问，定位2025数据入口，并区分年份、公开训练池、内部留出与真正独立测试。本次只读本地JSON/CSV及公开网页元数据，不下载MRI/GT/模型，不连接ECNU、不提交作业。

## 1. 先纠正年份和结论

本批次已完成推理的外部成品是 **2025 METS第一名 `brainles/brats25_met_gli-team`**，不是2024模型。当前fixed103来自公开2025 METS标注训练来源，由本项目再划为开发验证集；它不是独立的官方2024或2025测试集。目录整理日期、模型年份与扫描采集年份不能互相替代；本次没有核验扫描采集年份。

**已确认：镜像数据登记包含fixed103全部103/103病例。尚未确认：所用checkpoint各fold的实际梯度训练成员及选模/后处理拟合范围。** 因此用户怀疑的评估训练污染风险有具体证据支撑，不能仅用“成绩确实高”解释成外部泛化能力，也不能把登记交集直接升级为比赛作弊、推理读取GT或记忆训练样本的法证结论。

## 3. 103/103交集如何得到

1. 读取本地已提取的镜像`RAW_IMAGE_DATASET.json`，取`dataset`字典键，得到1296个病例ID；与`numTraining=1296`一致。
2. 用Conda base标准库`csv.DictReader`读取冻结清单的`source_case_id`，共103行、103唯一ID、无重复。
3. 集合交叉得到103个相同ID、缺失列表空；与原[登记暴露审计](IMAGE2025_REGISTRY_EXPOSURE.json)一致。
4. 本次没有打开任何NIfTI或checkpoint，未做图像内容SHA/患者身份跨年度法证比对。**这是精确登记ID交集，不是1296病例实际训练过程的重演。**

## 4. 对现有成绩意味着什么

| 模型 | 对fixed103已知暴露情况 | 允许的解释 |
|---|---|---|
| K1-175 / 原比赛E-200 | 本项目训练患者划分与103无交集，但103用于开发、选模和报告 | 开发验证表现，不是完全未参与决策的最终测试 |
| 2025冠军镜像 | 数据登记103/103交集；实际checkpoint fold成员、选模和阈值拟合范围未知 | 同公开数据来源的成品描述性表现，独立泛化未建立 |
| 2026 Bio-Intel完整A5+B2 | 公开五折与103/103交集，每例在四个train折；完整Model A集成不是OOF | 公开声明split显示训练暴露；不能用完整集成证明未曝光泛化 |

Bio-Intel即使按病例只选其val折，已有核查显示54/103存在同患者其他扫描在该折train，且Model B仅发布1/3折，不能简单构造完整同规格OOF。以上公开split与患者组交叉的来源见[可行性报告](../../../05_documents/07_references/20261104_external_models_fixed103_feasibility/REPORT.md)。

现有72项分数、配对CI和推理完成证据**不删除、不改写**。2025 WT病灶Dice0.703347对K1的0.630263和原E的0.617613，只支持该固定队列上的描述性差异；统一评分器控制了评分差异，但不能消除各模型训练/选模暴露差异。未证实推理时访问GT，也未证实竞赛官方隐藏测试泄漏，不提出对队伍违规的指控。

## 5. 真正能检验这个疑问的下一步

1. 向2025模型作者索取实际所用checkpoint的fold病例名单、患者划分、模型选择和后处理拟合范围；不能仅靠`dataset.json`的全集登记断言每个fold都用了全集。
2. 对候选2024/2025/其他外部队列与所有模型训练来源做病例、患者、纵向扫描及版本对应核查。ID重命名会漏检，影像SHA变化也可能仅来自重压缩/重采样；若进一步授权内容核验，需要明确几何与影像等价规则。
3. 只在所有模型都未训练、选模或拟合，且无同患者纵向暴露的有合法GT队列上冻结一次统一评估。另一种问题是让各方法按我们同一患者split、同预算重新训练；那是方法公平比较，不是现成权重泛化比较。
4. 换成2024不是自动解决方案：旧年度可能被后续模型训练使用，也可能复用患者/扫描；治疗前后、RC标注与来源分布不同还会带来额外混杂。本次未证实跨年度的具体复用比例。
5. 内部locked104/master test130同样来自公开训练来源，不能自动解除锁定或假定它们对外部模型独立；官方179没有公开GT，不能拿现有103结果冒充官方测试成绩。
