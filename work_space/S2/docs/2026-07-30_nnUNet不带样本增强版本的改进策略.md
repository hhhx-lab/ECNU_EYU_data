# nnUNet 不带样本增强版本的改进策略

本文记录 S2 无样本增强路线的改进矩阵、最终选型和结果路径。

## 评估范围

- 数据集：`Dataset264_BraTS2026_MET_Completion`
- 固定划分：`1035 train / 103 val / 104 locked test`
- 固定验证：`103` 例

## 改进矩阵

- `B`：`nnUNetTrainerBraTS2026RCCompletionFineTune`
- `A-1`：仅改架构
- `E`：`nnUNetTrainerBraTS2026RCFocalCompletionFineTune`
- `A-1+E`：架构 + Focal

## 结果路径

- 冻结选择：`work_space/S2/results/s2_small_lesion_ablation_20260721/checkpoint_selection.json`
- 总结比较：`work_space/S2/results/s2_small_lesion_ablation_20260721/final_comparison_20260724.md`
- 风险复核：`work_space/S2/results/s2_small_lesion_ablation_20260721/risk_review_20260724.md`
- 内部评估镜像：`work_space/S2/results/s2_eval_results/panoptica_evaluation_summary.json`

## 关键结论

- 总体保守基线：`B`
- 小病灶后续基座：`E`
- `A-1` 不选，`A-1+E` 也不选

## 选型理由

- `E` 的 WT all-instance F1 最高，且 WT small-instance F1 从 `0.277048` 提升到 `0.333083`
- `E` 的 RC all-instance F1 从 `0.236232` 提升到 `0.421053`
- `A-1` 与 `A-1+E` 都存在总体指标退化或 FP 增大问题

## 备注

这份策略文档只覆盖“无样本增强”的内部消融，不代表官方 179 例提交结果。
