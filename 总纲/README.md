## 三层信息

1. 本目录的中文专题文档：人工核对后的研究脉络、关键结果和证据边界。
2. 每次索引快照中的实验登记、数据与模型实体：把批次与实际目录绑定。
3. 完整文件树、全部文件CSV和分页目录：每个物理文件都有路径、用途、模块、说明依据和检查方式。包含历史区、隐藏文件及本总纲，不只收录“好看的结果”。

每个实验包内部原有的 `00_说明_20260919.md` 仍可作为就近入口；发生冲突时，应进一步检查同批次最终验收、原始指标、checkpoint身份及失败记录，不能只选对自己有利的说明。

## 使用边界

- 本次复核是**本地证据复核**，没有连接服务器、训练、重新评估或上传比赛平台。
- 完整路径覆盖不等于逐体素检查全部NIfTI、逐页审读全部PDF或加载全部checkpoint。自动索引会明确写出是人工上下文、AST/结构读取，还是路径推断。
- 未知的实验日期保留 `undated`；`20260919_archived_local_release` 的日期是整理日期，不能当成实验日期。
- 旧失败证据和旧解释保留。总纲负责说明差异，不改写历史以制造成功。
- 科学结果仍为 `artifact_status=experimental_unvalidated`、`operator_approved=false`、`formal_gate_status=not_run_not_passed`。本地文件验收pass不是科学优越性pass。

总纲会通过项目级 [AGENTS.md](../AGENTS.md) 的维护要求和索引校验命令持续更新；它不是后台定时任务，也不会自行启动远端实验。
