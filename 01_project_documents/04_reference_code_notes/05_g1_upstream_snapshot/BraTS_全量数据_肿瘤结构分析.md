## 对当前代码的结论

**96^3 单 crop 策略对这 1,296 例数据完全不可行：**

1. **94% 患者多发**，平均 15 个病灶/例，最高 462 个
2. **42% 的病灶 < 27mm^3**，几乎一半的病灶在 96^3 crop 中不可见
3. **63% 的患者病灶散布 > 80mm**，远超单个 96^3 crop（~48mm 视野）的覆盖范围

必须实施的改造：
- 连通域分析 + 每病灶独立成行（CSV 创建）
- 多 crop 逐病灶生成 + 全脑拼接（推理）
- 缩小 crop 至 64^3（训练/推理效率）
- 小病灶加权采样（训练）

详细信息参见 `BraTS2026_转移瘤扩散模型改造分析.md`。
